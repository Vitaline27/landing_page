# landing_page

## About

This project is the landing page of a website for a French teacher.

## Technologies

- HTML5
- CSS
- Git
- GitHub

## How to run

Open `index.html` in a web browser.

## Challenges

- **Sizing the hero image.** My picture was much bigger than its flex container and overflowed. Setting `min-width: 0` on the container and a fixed `height` with `object-fit: cover` on the image fixed it.
- **Default margins.** The `p` elements had a default margin that added to my padding.
- **Page margins.** I was not sure how to create the margin of the landing page so I added a 15% left and right padding to each section. There are certainly better ways to achieve this.

## What I learned

- How to use different elements to create an HTML page. (`header`, `nav`, `main`, `section`, `figure`, `footer`). These elements are block-level by default, so they don't need to be placed inside a flex container.
- `<p>` and `<h1>,<h2>`,etc. elements have default margins.
- How to size pictures with `object-fit`. But, I still need to practice this new CSS property.
